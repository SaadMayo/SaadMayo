# ElectroHub

Website for ElectroHub, Multan: iPhone, Samsung Galaxy and gaming laptops.

- `index.html` is the complete website in one file (images included). Open it in any browser.
- `assets/` holds the original logo and product images.

## Publish with GitHub Pages

1. Upload these files to the repository root.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, pick **Deploy from a branch**, then branch `main` and folder `/ (root)`. Save.
4. After a minute the site is live at `https://<username>.github.io/<repo>/`.
